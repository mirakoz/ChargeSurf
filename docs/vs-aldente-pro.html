ChargeSurf vs AlDente Pro

Two battery charge limiters for MacBooks, compared feature by feature. AlDente Pro is the mature, paid, closed-source choice; ChargeSurf is free, open source and focused on Apple Silicon MacBooks on macOS 27.

Which one to choose

Choose AlDente Pro if

  • you have an Intel MacBook or run macOS 12 to 26,
  • you want discharge, calibration, MagSafe LED control, schedules or Apple Shortcuts,
  • you want a mature app with email support.

Choose ChargeSurf if

  • you want a free tool whose source code you can read and build yourself,
  • you need the core features (a charge range, holding the charge on adapter power, heat protection, a one-time top-up) on an Apple Silicon MacBook with macOS 27,
  • you also want to see the battery level and health of the iPhone, iPad or AirPods charging from your Mac.

AlDente also has a free version, with a charge limiter and manual discharge. Whichever you pick, run only one charge limiter at a time: two tools will fight over the same macOS setting.

macOS 27 support

On macOS 27 release builds, the SMC charge-control keys that charge limiters used to write directly are restricted to a private Apple entitlement. ChargeSurf goes through macOS's own charge-limit mechanism instead (how it works). AlDente's release notes describe a "completely rebuilt charge control with macOS 27 support" in version 1.39.
